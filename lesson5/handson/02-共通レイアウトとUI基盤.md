## はじめに

アプリ全体の共通レイアウト骨組みを用意し最低限のヘッダー/フッターとコンテンツ余白を整える。

## 目的

共通`layout.tsx`で全ページの骨組みを定め、ヘッダー/フッター枠を用意し、ナビゲーション導線と余白を統一すること。

## 課題A：レイアウトを作る（8分）

8分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

レイアウトを作り画面全体のレイアウトを整える。

- 対象ファイル:`src/app/layout.tsx`
- 構成: 最上位に`html lang="ja"`→`body`→その子に`header`/`main`/`footer`の順で縦並び
- 後続課題でヘッダー内容とフッター文字列を追加予定のためこの課題では中身を空にする

【使用タグ】
- `html`
  - `body`
    - （新規）`div`: 全体を縦方向に並べるためのラッパー
      - （新規）`header`: ページ上部の領域を用意
      - （新規）`main`: 主コンテンツ領域を用意
      - （新規）`footer`: ページ下部の領域を用意

### ヒント

- 空の`header`/`footer`は後続で中身追加

- 使用クラス一覧:
  - `div（body直下）`: `min-h-screen`, `flex`, `flex-col`, `bg-white`
  - `header`: `border-b`, `border-pink-200`
  - `main`: `flex-1`
  - `div（main内ラッパー）`: `max-w-3xl`, `mx-auto`, `px-4`, `py-6`, `space-y-6`
  - `footer`: `border-t`, `border-pink-200`

### 解答例

```tsx
import type { Metadata } from 'next';
import './globals.css';

export const metadata: Metadata = {
  title: 'MiniShop Lesson5',
  description: 'Server / Client Components & Server Actions Lesson',
};

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html lang="ja">
      <body>
        <div className="min-h-screen flex flex-col bg-white">
          <header className="border-b border-pink-200">{/* 省略 */}</header>
          <main className="flex-1">
            <div className="max-w-3xl mx-auto px-4 py-6 space-y-6">{children}</div>
          </main>
          <footer className="border-t border-pink-200">{/* 省略 */}</footer>
        </div>
      </body>
    </html>
  );
}
```

## 課題B：ヘッダーとナビを追加（12分）

12分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

ヘッダー内にアプリタイトルとナビリンク（商品/注文/カート）を配置し全ページ共通の移動導線を提供する。

- 対象ファイル:`src/app/layout.tsx`（課題Aの続き編集）
- 追加コンポーネント: `Header`関数コンポーネント（ローカル）
  - タイトル表示: 左側に`MiniShop`文字列。クリックで`/products`へ遷移
  - ナビリンク: 右側に`/products`→「商品」`/orders`→「注文」`/cart`→「カート」順

【使用タグ】
- `header`
  - （新規）`div`: 内部幅を制御するラッパー
    - （新規）`div`: ヘッダー内容のラッパー
      - （新規）`Link`: タイトルリンク（/products）
      - （新規）`nav`
        - （新規）`Link`: 商品
        - （新規）`Link`: 注文
        - （新規）`Link`: カート

### ヒント

- `import Link from 'next/link'`
- タイトルとナビを`flex`+`gap`
- 使用クラス一覧（新規のみ）:
  - `div（header内ラッパー）`: `max-w-3xl`, `mx-auto`, `px-4`, `h-14`, `flex`, `items-center`, `justify-between`
  - `div（ヘッダー内容ラッパー）`: `flex`, `items-center`, `gap-6`
  - `Link（タイトル）`: `font-semibold`, `text-pink-600`
  - `nav`: `flex`, `gap-4`, `text-sm`
  - `Link（各ナビ）`: `text-gray-700`, `hover:text-pink-600`

### 解答例

```tsx
import type { Metadata } from 'next';
import Link from 'next/link';
import './globals.css';

export const metadata: Metadata = {
  title: 'MiniShop Lesson5',

  return (
    <html lang="ja">
      <body>
        <div className="min-h-screen flex flex-col bg-white">
          <Header />

            <div className="max-w-3xl mx-auto px-4 py-6 space-y-6">{children}</div>
          </main>
          <footer className="border-t border-pink-200">{/* 後続課題で文言追加 */}</footer>
        </div>
      </body>
    </html>
  );
}

function Header() {
  return (
    <header className="border-b border-pink-200">
      <div className="max-w-3xl mx-auto px-4 h-14 flex items-center justify-between">
        <div className="flex items-center gap-6">
          <Link href="/products" className="font-semibold text-pink-600">
            MiniShop
          </Link>
          <nav className="flex gap-4 text-sm">
            <Link href="/products" className="text-gray-700 hover:text-pink-600">
              商品
            </Link>
            <Link href="/orders" className="text-gray-700 hover:text-pink-600">
              注文
            </Link>
            <Link href="/cart" className="text-gray-700 hover:text-pink-600">
              カート
            </Link>
          </nav>
        </div>
      </div>
    </header>
  );
}
```

## 課題C：フッター文言と体裁追加（8分）

8分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

フッターにコピーライト表記を配置する。

- 対象ファイル:`src/app/layout.tsx`（課題Bの続き編集）
- 追加コンポーネント: `Footer`関数コンポーネント
  - 表示文言: `© 2025 MiniShop`

【使用タグ】
- `footer`
  - （新規）`div`: 内部幅を制御するラッパー
    - （新規）`p`: コピーライト

### ヒント

- 使用クラス一覧（新規/変更）:
  - `footer（変更）`: `mt-8`
  - `div（footer内ラッパー）`: `max-w-3xl`, `mx-auto`, `px-4`, `py-4`
  - `p（コピーライト）`: `text-center`, `text-xs`, `text-gray-500`

### 解答例

```tsx
import type { Metadata } from 'next';
import Link from 'next/link';
import './globals.css';

export const metadata: Metadata = {
  title: 'MiniShop Lesson5',
  description: 'Server / Client Components & Server Actions Lesson',
};

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html lang="ja">
      <body>
        <div className="min-h-screen flex flex-col bg-white">
          <Header />
          <main className="flex-1">
            <div className="max-w-3xl mx-auto px-4 py-6 space-y-6">{children}</div>
          </main>
          <Footer />
        </div>
      </body>
    </html>
  );
}

function Header() {
  return (
    <header className="border-b border-pink-200">
      <div className="max-w-3xl mx-auto px-4 h-14 flex items-center justify-between">
        <div className="flex items-center gap-6">
          <Link href="/products" className="font-semibold text-pink-600">
            MiniShop
          </Link>
          <nav className="flex gap-4 text-sm">
            <Link href="/products" className="text-gray-700 hover:text-pink-600">
              商品
            </Link>
            <Link href="/orders" className="text-gray-700 hover:text-pink-600">
              注文
            </Link>
            <Link href="/cart" className="text-gray-700 hover:text-pink-600">
              カート
            </Link>
          </nav>
        </div>
      </div>
    </header>
  );
}

function Footer() {
  return (
    <footer className="border-t border-pink-200 mt-8">
      <div className="max-w-3xl mx-auto px-4 py-4">
        <p className="text-center text-xs text-gray-500">© 2025 MiniShop</p>
      </div>
    </footer>
  );
}
```
