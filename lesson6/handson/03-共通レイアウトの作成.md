## はじめに
アプリケーション全体で使用する共通の型定義、表示コンポーネント、およびレイアウト（ヘッダー・フッター）を作成します。
これにより、各ページの実装時に共通部分を再利用できるようになります。

## 目的
- 共通の型定義ファイルを作成する
- データを一覧表示する共通コンポーネントを作成する
- `layout.tsx` を編集してヘッダーとフッターを配置する

## 課題A：型定義の作成（5分）

- 対象ファイル: `src/types/recipe.ts`

  - `title`: 文字列
  - `content`: 文字列
  - `author`: 文字列
  - `date`: 文字列
  - `category`: 文字列

【使用タグ】

## 課題B：共通コンポーネントの作成（10分）

10分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

レシピの一覧を表示する共通コンポーネントを作成する。

- 対象ファイル: `src/app/components/RecipeList.tsx`
  - Props:
    - `recipes`: `Recipe` 型の配列（必須）
    - `linkToDetail`: 真偽値（任意）。`true` の場合のみ詳細リンクを表示
  - 表示内容:
    - `ul` タグでリスト表示
    - 各アイテムに日付、タイトル、著者名を表示
    - `linkToDetail` が`true`の場合のみ詳細リンクを表示

【使用タグ】
- `ul`: リスト全体。グリッドレイアウトで要素間に隙間を設ける。
  - `li`: 各レシピアイテム。白背景で角丸、内側に余白を持たせる。
    - `div`: 日付表示。ピンク色で小さめの文字。
    - `div`: タイトル表示。太字で強調。
    - `div`: 著者名表示。グレーで小さめの文字。
    - `Link`: 詳細ページへのリンク（条件付き）。青色でリンクであることを示す。

【命名】
- コンポーネント: `RecipeList`
- Props型: `Props`

【参照】
- インポート識別子: `Link`, `Recipe`

### ヒント

- 使用クラス一覧:
  - `ul`: `grid`, `gap-3`
  - `li`: `bg-white`, `rounded`, `p-3`
  - `div（日付）`: `text-pink-600`, `text-sm`
  - `div（タイトル）`: `font-semibold`
  - `div（著者名）`: `text-slate-500`, `text-sm`
  - `Link`: `text-blue-600`

### 解答例

```tsx
import Link from 'next/link';
import type { Recipe } from '@/types/recipe';

type Props = {
  recipes: Recipe[];
  linkToDetail?: boolean; // ISR でのみ true
};

export function RecipeList({ recipes, linkToDetail }: Props) {
  return (
    <ul className="grid gap-3">
      {recipes.map((r) => (
        <li key={r.id} className="bg-white rounded p-3">
          <div className="text-pink-600 text-sm">{r.date}</div>
          <div className="font-semibold">{r.title}</div>
          <div className="text-slate-500 text-sm">by {r.author}</div>
          {linkToDetail ? (
            <Link href={`/recipes-isr/${r.id}`} className="text-blue-600">
              詳細へ →
            </Link>
          ) : null}
        </li>
      ))}
    </ul>
  );
}
```

## 課題C：共通レイアウトの実装（10分）

10分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

全ページ共通のヘッダーとフッターを実装し、画面全体のレイアウトを整える。

- 対象ファイル: `src/app/layout.tsx`
- メタデータ: 以下の内容に書き換える
  ```ts
  export const metadata: Metadata = {
    title: 'Recipes',
    description: 'CSR / SSR / SSG / ISR を比べて学ぶ',
  };
  ```

【使用タグ】
- `html`
  - `body`
    - `div`: ページ全体のラッパー。画面の高さを確保し、ヘッダー・メイン・フッターを縦に並べる。
      - `header`: ヘッダー領域。ピンク背景で白文字。
        - `div`: ヘッダー内部の幅制御コンテナー。最大幅を設定し中央寄せ。左右に要素を配置。
          - `Link`: アプリタイトル。「RecipeModes」を表示し、`/recipes-ssg`へ遷移。太字で強調。
          - `nav`: ナビゲーションリンクのラッパー。横並びで要素間に隙間を設ける。
            - `Link`:「CSR」を表示し、`/recipes-csr`へ遷移。ホバー時に下線を表示。
            - `Link`:「SSR」を表示し、`/recipes-ssr`へ遷移。ホバー時に下線を表示。
            - `Link`:「SSG」を表示し、`/recipes-ssg`へ遷移。ホバー時に下線を表示。
            - `Link`:「ISR」を表示し、`/recipes-isr`へ遷移。ホバー時に下線を表示。
      - `main`: メインコンテンツ領域。最大幅を設定し中央寄せ。全幅を確保し内側に余白を持たせる。
      - `footer`: フッター領域。薄いグレー背景でグレー文字。
        - `div`: フッター内部の幅制御コンテナー。最大幅を設定し中央寄せ。内側に余白を持たせる。「© 2025 Recipes」を表示。

【命名】
- コンポーネント: `RootLayout`（既存）

【参照】
- インポート識別子: `Link`

### ヒント

- 使用クラス一覧:
  - `div（ラッパー）`: `min-h-screen`, `grid`, `grid-rows-[auto_1fr_auto]`
  - `header`: `bg-pink-500`, `text-white`
  - `div（ヘッダー内部）`: `max-w-3xl`, `mx-auto`, `flex`, `justify-between`, `p-3`
  - `Link（タイトル）`: `font-bold`
  - `nav`: `flex`, `gap-3`
  - `Link（ナビ）`: `hover:underline`
  - `main`: `max-w-3xl`, `mx-auto`, `w-full`, `p-4`
  - `footer`: `bg-slate-50`, `text-slate-500`
  - `div（フッター内部）`: `max-w-3xl`, `mx-auto`, `p-3`

### 解答例

```tsx
import type { Metadata } from 'next';
import { Geist, Geist_Mono } from 'next/font/google';
import './globals.css';
import Link from 'next/link';

const geistSans = Geist({
  variable: '--font-geist-sans',
  subsets: ['latin'],
});

const geistMono = Geist_Mono({
  variable: '--font-geist-mono',
  subsets: ['latin'],
});

export const metadata: Metadata = {
  title: 'Recipes',
  description: 'CSR / SSR / SSG / ISR を比べて学ぶ',
};

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html lang="ja">
      <body className={`${geistSans.variable} ${geistMono.variable} antialiased`}>
        <div className="min-h-screen grid grid-rows-[auto_1fr_auto]">
          <header className="bg-pink-500 text-white">
            <div className="max-w-3xl mx-auto flex justify-between p-3">
              <Link href="/recipes-ssg" className="font-bold">
                Recipes
              </Link>
              <nav className="flex gap-3">
                <Link href="/recipes-csr" className="hover:underline">
                  CSR
                </Link>
                <Link href="/recipes-ssr" className="hover:underline">
                  SSR
                </Link>
                <Link href="/recipes-ssg" className="hover:underline">
                  SSG
                </Link>
                <Link href="/recipes-isr" className="hover:underline">
                  ISR
                </Link>
              </nav>
            </div>
          </header>
          <main className="max-w-3xl mx-auto w-full p-4">{children}</main>
          <footer className="bg-slate-50 text-slate-500">
            <div className="max-w-3xl mx-auto p-3">© 2025 Recipes</div>
          </footer>
        </div>
      </body>
    </html>
  );
}
```
