## はじめに
本ハンズオンでは、Next.jsの4つのレンダリング方式（CSR/SSR/SSG/ISR）を比較できるレシピカタログアプリケーションを作成します。
第1章では、Next.jsプロジェクトの新規作成と初期設定を行い、トップページを表示します。

## 目的
- Next.jsプロジェクトを新規作成する
- 開発サーバーを起動して動作確認する
- トップページを編集して表示内容を変更する

## プロジェクトの作成
1. ターミナルでデスクトップなどの作業ディレクトリに移動し、以下のコマンドを実行して新規プロジェクトを作成します。
   ```bash
   npx create-next-app@latest recipes-app --typescript --eslint --tailwind --src-dir --app --import-alias "@/*" --use-npm
   ```
   - 質問が表示された場合はすべてデフォルト（Enterキー）で進めます。

2. 作成されたディレクトリに移動します。
   ```bash
   cd recipes-app
   ```

## アプリケーションのビルドと起動
1. 以下のコマンドでアプリケーションをビルドし、起動します。
   ```bash
   npm run build
   npm run start
   ```
2. ブラウザで `http://localhost:3000` にアクセスし、Next.jsのデフォルトページが表示されることを確認します。
3. 確認できたらターミナルで `Ctrl + C` を押してサーバーを停止します。

## トップページの編集
1. `src/app/page.tsx` を開き、以下の内容に書き換えます。
   - 不要なデフォルトのコードを削除し、シンプルな見出しと説明文のみにします。

   ```tsx
   export default function Home() {
     return (
       <section className="grid gap-3">
         <h1 className="text-2xl font-bold">Next.js レンダリング比較</h1>
         <p className="text-slate-600">ヘッダーのリンクから CSR / SSR / SSG / ISR を確認できます。</p>
       </section>
     );
   }
   ```

## グローバルスタイルの調整
1. `src/app/globals.css` を開き、以下の内容に書き換えます。
   - Tailwind CSS v4の設定と、基本のフォント設定のみを残します。

   ```css
   @import "tailwindcss";

   :root {
     --background: #ffffff;
     --foreground: #171717;
   }

   @theme inline {
     --color-background: var(--background);
     --color-foreground: var(--foreground);
     --font-sans: var(--font-geist-sans);
     --font-mono: var(--font-geist-mono);
   }

   @media (prefers-color-scheme: dark) {
     :root {
       --background: #0a0a0a;
       --foreground: #ededed;
     }
   }

   body {
     background: var(--background);
     color: var(--foreground);
     font-family: Arial, Helvetica, sans-serif;
   }
   ```

- 以下のコマンドを実行してアプリケーションを起動します。
  ```bash
  npm run build
  npm run start
  ```
- ブラウザで `http://localhost:3000` にアクセスし、以下の状態になっていることを確認します。

  - 「Next.jsレンダリング比較」という見出しが表示されている
  - その下に説明文が表示されている
