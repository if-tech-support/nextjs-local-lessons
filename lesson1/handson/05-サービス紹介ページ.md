## はじめに
サービス紹介ページ（`/service`）にサービスカテゴリとその詳細カードを表示します。各課題は、ヒントを参考に仕様どおり自力で取り組み、その後に解答例で確認しましょう。

## 目的

- タイトルと複数セクション（カテゴリ）＋カードで構成されたページを実装する
- カテゴリ見出しと詳細カードを整える

## 学習対象のスキル

- 中央寄せ・最大幅のコンテナー設計（中央寄せ、最大幅、左右の内側余白）。
- 見出しの基本装飾（青色、太字、サイズ、上下余白）。
- セクションブロックの構成（見出し＋カード群、区切り線と余白）。
- 配列データを`map`でカテゴリとカードを反復描画する。

## 課題A：ページの基本レイアウトとタイトル（5分）

5分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

ページ全体の基本レイアウトを作ります。

- 編集するファイル: `src/app/service/page.tsx`
- 外側コンテナー: `<div>`。画面中央に配置する。
- タイトル: `<h2>`。英字 "SERVICE" を表示する。
- 一覧ラッパー: `<div>`。タイトル直下に置く（ブロックは後続課題で追加）。

【使用タグ】
- （新規）`<div>`: 中央寄せ、最大幅、左右の余白
  - （新規）`<h2>`: やや大きい文字サイズ、太字、青系文字色、上下に余白
  - （新規）`<div>`: 縦方向に積む、横幅いっぱい、上下に余白

### ヒント

- 使用クラス一覧:
  - `div`: `mx-auto`, `max-w-[960px]`, `px-4`
  - `h2`: `text-2xl`, `font-bold`, `text-blue-700`, `py-8`
  - `div`: `flex`, `flex-col`, `w-full`, `py-4`

### 解答例

```tsx
export default function Service() {
  return (
    <div className="mx-auto max-w-[960px] px-4">
      <h2 className="text-2xl font-bold text-blue-700 py-8">SERVICE</h2>
      <div className="flex flex-col w-full py-4">{/* セクションブロックは課題B以降で追加 */}</div>
    </div>
  );
}
```

## 課題B：1つ目のカテゴリ（8分）

8分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

最初のカテゴリ（1ブロック）とそのカードを追加します。

- 編集するファイル: `src/app/service/page.tsx`
- カテゴリブロック: `<div>`。
- カテゴリ見出し: `<h3>`。
- カード: `<div>`。
  - カードタイトル: `<p>`。
  - 本文: `<p>`。
- 余計な入れ子は作らない（外側→タイトル→一覧ラッパー→ブロック→カード）。

【使用タグ】
- `<div>`
  - `<h2>`
  - `<div>`
    - （新規）`<div>`: 上下に余白、末尾に区切り線
      - （新規）`<h3>`: やや大きい文字サイズ
      - （新規）`<div>`: 淡い青背景、角丸、全方向に余白、影
        - （新規）`<p>`: 標準サイズ、太字、下に小さな余白
        - `<p>`

### ヒント

- 使用クラス一覧:
  - `div`: `space-y-4`, `py-4`, `border-b`, `border-blue-100`
  - `h3`: `text-lg`
  - `div`: `bg-blue-50`, `rounded`, `p-4`, `shadow`
  - `p`: `text-base`, `font-bold`, `mb-2`

### 解答例

```tsx
export default function Service() {
  return (
    <div className="mx-auto max-w-[960px] px-4">
      <h2 className="text-2xl font-bold text-blue-700 py-8">SERVICE</h2>
      <div className="flex flex-col w-full py-4">
        <div className="space-y-4 py-4 border-b border-blue-100">
          <h3 className="text-lg">1. Web開発</h3>
          <div className="bg-blue-50 rounded p-4 shadow">
            <p className="text-base font-bold mb-2">カスタムWebサイト開発</p>
            <p>クライアントのビジネスニーズに合わせたオーダーメイドのウェブサイトを開発します。</p>
          </div>
        </div>
      </div>
    </div>
  );
}
```
