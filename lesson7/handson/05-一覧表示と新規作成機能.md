## はじめに
Prisma Clientを使用してデータベースからデータを取得し、Server Actionsを使って新しいデータを保存する機能を実装します。

## 目的
- Server Actionsでフォームデータを受け取り、データベースに保存する
- Prisma Clientでデータベースから一覧データを取得して表示する
- `revalidatePath` を使用してキャッシュを更新し、画面を最新化する

## 学習対象のスキル
- `prisma.link.create` / `prisma.link.findMany`

## 課題A：Server Actionsを作成する（15分）

15分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

`src/app/links/actions.ts` を作成し、リンク作成処理を実装します。

- 対象ファイル: `src/app/links/actions.ts`
- 宣言位置: ファイル先頭に `'use server'` を記述
- インポート:
  - `next/navigation` から `redirect`
  - `next/cache` から `revalidatePath`
  - `@/lib/prisma` から `prisma`
- 定数: `LINKS_PATH` を `'/links'` と定義
- 関数: `ensureString(value: FormDataEntryValue | null, fieldName: string)`
  - 入力: フォーム値とフィールド名
  - 検証: 文字列でない場合はエラー「{fieldName}は必須です。」
  - 検証: 空文字の場合はエラー「{fieldName}を入力してください。」
  - 戻り値: トリムした文字列
- 関数: `parseUrl(value: FormDataEntryValue | null)`
  - 入力: フォーム値
  - 処理: `ensureString` で値を取得
  - 検証: `new URL()` で検証し、失敗時はエラー「URLは https://example.com のようにプロトコル付きの絶対URLで入力してください。」
  - 戻り値: `toString()` したURL文字列
- アクション関数: `createLink(formData: FormData)`（非同期、エクスポート）
  - 入力: `FormData`
  - 処理: `title` と `url` を取得・検証（ユーティリティ使用）
  - 保存: `prisma.link.create` でデータを保存（`data: { title, url }`）
  - 再検証: `revalidatePath(LINKS_PATH)` を実行
  - 遷移: `redirect(LINKS_PATH)` を実行

【命名】
- 関数: `ensureString`, `parseUrl`, `createLink`
- 定数: `LINKS_PATH`

【参照】
- インポート識別子: `redirect`, `revalidatePath`, `prisma`

【使用タグ】
- なし（サーバーコードのため）

### ヒント

- `FormData` からの値取得には `formData.get('name')` を使用します。
- `prisma.link.create` は非同期処理なので `await` が必要です。

### 解答例

```ts
'use server';

import { redirect } from 'next/navigation';
import { revalidatePath } from 'next/cache';
import { prisma } from '@/lib/prisma';

const LINKS_PATH = '/links';

// 入力値を文字列として取り出し、空文字を排除するユーティリティ
const ensureString = (value: FormDataEntryValue | null, fieldName: string): string => {
  if (typeof value !== 'string') {
    throw new Error(`${fieldName}は必須です。`);
  }
  const trimmed = value.trim();
  if (!trimmed) {
    throw new Error(`${fieldName}を入力してください。`);
  }
  return trimmed;
};

// hidden inputのIDなど数値系の検証を一本化
const parseNumericId = (value: FormDataEntryValue | null): number => {
  const asNumber = Number(value);
  if (!Number.isInteger(asNumber) || asNumber <= 0) {
    throw new Error('有効なリンクIDが必要です。');
  }
  return asNumber;
};

// URL形式を検証し、常に絶対URLとして保存
const parseUrl = (value: FormDataEntryValue | null): string => {
  const urlString = ensureString(value, 'url');
  try {
    const normalized = new URL(urlString);
    return normalized.toString();
  } catch {
    throw new Error('URLは https://example.com のようにプロトコル付きの絶対URLで入力してください。');
  }
};

// 一覧で使用する作成アクション。完了後に一覧へリダイレクト
export async function createLink(formData: FormData) {
  const title = ensureString(formData.get('title'), 'title');
  const url = parseUrl(formData.get('url'));

  await prisma.link.create({
    data: {
      title,
      url,
    },
  });

  revalidatePath(LINKS_PATH);
  redirect(LINKS_PATH);
}

// 詳細ページから呼ばれる更新アクション
export async function updateLink(formData: FormData) {
  const id = parseNumericId(formData.get('id'));
  const title = ensureString(formData.get('title'), 'title');
  const url = parseUrl(formData.get('url'));

  await prisma.link.update({
    where: { id },
    data: {
      title,
      url,
    },
  });

  revalidatePath(LINKS_PATH);
  revalidatePath(`${LINKS_PATH}/${id}`);
  redirect(`${LINKS_PATH}/${id}`);
}

// リストアイテムの削除アクション。パスを再検証して一覧へ戻る
export async function deleteLink(formData: FormData) {
  const id = parseNumericId(formData.get('id'));

  await prisma.link.delete({ where: { id } });

  revalidatePath(LINKS_PATH);
  redirect(LINKS_PATH);
}
```

## 課題B：一覧ページでデータ取得と作成を行う（10分）

10分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

`src/app/links/page.tsx` を編集し、ダミーデータをPrismaによるデータ取得に置き換え、フォームのアクションを設定します。

- 対象ファイル: `src/app/links/page.tsx`
- インポート:
  - `./actions` から `createLink`
  - `@/lib/prisma` から `prisma`
- `LinksPage` コンポーネント:
  - 既存のダミー配列 `const links = [...]` を削除。
  - `prisma.link.findMany` を実行して `links` を取得。
    - オプション: `orderBy: { createdAt: 'desc' }`（作成日時の降順）。
  - `form` タグの `action` 属性に `createLink` を設定。

【命名】
- なし

【参照】
- インポート識別子: `createLink`, `prisma`

【使用タグ】
- `div`: 全体のラッパー。要素間に縦方向の余白を設ける。
  - `div`: 新規作成フォームのコンテナー。角丸、枠線、背景色を設定。
    - `h1`: 見出し。「リンクを保存する」を表示。
    - `form`: 入力フォーム。グリッドレイアウトで要素を配置。`action`属性に`createLink`を設定。
      - `label`: タイトル入力欄のラベル。
        - `input`: テキスト入力。`name="title"`。
      - `label`: URL入力欄のラベル。
        - `input`: URL入力。`name="url"`。
      - `button`: 送信ボタン。「追加する」を表示。
  - `div`: 一覧表示エリアのコンテナー。
    - `h2`: 見出し。「保存済みリンク」を表示。
    - `p`: データなし時のメッセージ（条件付き）。
    - `ul`: リンク一覧（条件付き）。
      - `li`: 各リンクアイテム。
        - `a`: 外部リンク。タイトルを表示。
        - `p`: URLを表示。
        - `div`: 操作ボタンのラッパー。
          - `Link`: 詳細ページへのリンク。
          - `form`: 削除用フォーム。
            - `input`: 隠しフィールドでIDを保持。
            - `button`: 削除ボタン。

### ヒント

- `LinksPage` は `async` 関数である必要があります（すでにそうなっているはずです）。
- `prisma.link.findMany` は `await` して結果を受け取ります。
- 使用クラス一覧:
  - `div（全体）`: `space-y-8`
  - `div（フォーム枠）`: `space-y-4`, `rounded-xl`, `border`, `bg-slate-900`, `p-6`

### 解答例

```tsx
import Link from 'next/link';
import { createLink } from './actions';
import { prisma } from '@/lib/prisma';

// リンク一覧ページ
export default async function LinksPage() {
  const links = await prisma.link.findMany({
    orderBy: { createdAt: 'desc' },
  });

  return (
    <div className="space-y-8">
      <div className="space-y-4 rounded-xl border bg-slate-900 p-6">
        <h1 className="text-2xl font-semibold text-white">リンクを保存する</h1>

        <form action={createLink} className="mt-4 grid gap-4 md:grid-cols-2">
          <label className="flex flex-col gap-2 text-sm text-slate-100">
            タイトル
            <input
              className="rounded-lg border bg-slate-900 p-3"
              type="text"
              name="title"
              placeholder="タイトルを入力"
              required
            />
          </label>
          <label className="flex flex-col gap-2 text-slate-100 md:col-span-2">
            URL
            <input
              className="rounded-lg border bg-slate-900 p-3"
              type="url"
              name="url"
              placeholder="https://example.com"
              required
            />
          </label>
          <button type="submit" className="rounded-lg bg-emerald-400 py-2 text-slate-900 md:col-span-2">
            追加する
          </button>
        </form>
      </div>

      <div className="space-y-2">
        <h2 className="text-lg font-semibold text-white">保存済みリンク</h2>
        {links.length === 0 ? (
          <p className="rounded-xl border bg-slate-900 p-5 text-center">
            まだ登録がありません。上のフォームから追加してください。
          </p>
        ) : (
          <ul className="space-y-4">
            {links.map((link) => {
              return (
                <li key={link.id} className="space-y-3 rounded-xl border bg-slate-900 p-5">
                  <a href={link.url} target="_blank" rel="noreferrer" className="text-lg font-semibold text-white">
                    {link.title}
                  </a>
                  <p className="text-sm text-slate-400">{link.url}</p>
                  <div className="flex flex-wrap gap-3">
                    <Link href={`/links/${link.id}`} className="rounded-lg border px-4 py-2 text-white">
                      詳細
                    </Link>
                    <form>
                      <input type="hidden" name="id" value={link.id} />
                      <button type="submit" className="rounded-lg border px-4 py-2 text-red-200">
                        削除
                      </button>
                    </form>
                  </div>
                </li>
              );
            })}
          </ul>
        )}
      </div>
    </div>
  );
}
```
