## はじめに
詳細ページでデータベースから特定のデータを取得して表示し、フォームの内容を更新して保存する機能を実装します。

## 目的
- Server Actionsでデータの更新処理を実装する
- Prisma Clientで特定のデータを取得する (`findUnique`)
- データの存在確認を行い、存在しない場合は404ページを表示する

## 学習対象のスキル
- `prisma.link.update`

## 課題A：更新用Server Actionsを作成する（15分）

15分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

`src/app/links/actions.ts` に更新処理を追加します。

- 対象ファイル: `src/app/links/actions.ts`
- インポート:（既存ファイルのため追加なし）
- 関数: `parseNumericId(value: FormDataEntryValue | null)`
  - 入力: フォーム値
  - 検証: `Number()` で変換し、整数でない、または0以下の場合はエラー「有効なリンクIDが必要です。」
  - 戻り値: 数値
- アクション関数: `updateLink(formData: FormData)`（非同期、エクスポート）
  - 入力: `FormData`
  - 処理: `id` を取得・検証（`parseNumericId` 使用）
  - 処理: `title` と `url` を取得・検証（既存ユーティリティ使用）
  - 更新: `prisma.link.update` でデータを更新（`where: { id }`, `data: { title, url }`）
  - 再検証: `revalidatePath(LINKS_PATH)` を実行（一覧ページ）
  - 再検証: `revalidatePath('${LINKS_PATH}/${id}')` を実行（詳細ページ）
  - 遷移: `redirect('${LINKS_PATH}/${id}')` を実行

【命名】
- 関数: `parseNumericId`, `updateLink`

【参照】
- インポート識別子: `redirect`, `revalidatePath`, `prisma`（既存）

【使用タグ】
- なし（サーバーコードのため）

### ヒント

- `FormData` からの値取得には `formData.get('name')` を使用します。
- `prisma.link.update` は非同期処理なので `await` が必要です。
- `revalidatePath` は更新されたデータが表示されるすべてのページに対して実行するのが理想的です。

### 解答例

```ts
'use server';

import { redirect } from 'next/navigation';
import { revalidatePath } from 'next/cache';
import { prisma } from '@/lib/prisma';

const LINKS_PATH = '/links';

// 入力値を文字列として取り出し、空文字を排除するユーティリティ
const ensureString = (value: FormDataEntryValue | null, fieldName: string): string => {
  if (typeof value !== 'string') {
    throw new Error(`${fieldName}は必須です。`);
  }
  const trimmed = value.trim();
  if (!trimmed) {
    throw new Error(`${fieldName}を入力してください。`);
  }
  return trimmed;
};

// hidden inputのIDなど数値系の検証を一本化
const parseNumericId = (value: FormDataEntryValue | null): number => {
  const asNumber = Number(value);
  if (!Number.isInteger(asNumber) || asNumber <= 0) {
    throw new Error('有効なリンクIDが必要です。');
  }
  return asNumber;
};

// URL形式を検証し、常に絶対URLとして保存
const parseUrl = (value: FormDataEntryValue | null): string => {
  const urlString = ensureString(value, 'url');
  try {
    const normalized = new URL(urlString);
    return normalized.toString();
  } catch {
    throw new Error('URLは https://example.com のようにプロトコル付きの絶対URLで入力してください。');
  }
};

// 一覧で使用する作成アクション。完了後に一覧へリダイレクト
export async function createLink(formData: FormData) {
  const title = ensureString(formData.get('title'), 'title');
  const url = parseUrl(formData.get('url'));

  await prisma.link.create({
    data: {
      title,
      url,
    },
  });

  revalidatePath(LINKS_PATH);
  redirect(LINKS_PATH);
}

// 詳細ページから呼ばれる更新アクション
export async function updateLink(formData: FormData) {
  const id = parseNumericId(formData.get('id'));
  const title = ensureString(formData.get('title'), 'title');
  const url = parseUrl(formData.get('url'));

  await prisma.link.update({
    where: { id },
    data: {
      title,
      url,
    },
  });

  revalidatePath(LINKS_PATH);
  revalidatePath(`${LINKS_PATH}/${id}`);
  redirect(`${LINKS_PATH}/${id}`);
}
```

## 課題B：詳細ページでデータ取得と更新を行う（10分）

10分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

`src/app/links/[id]/page.tsx` を編集し、Prismaでデータを取得して更新アクションを接続します。

- 対象ファイル: `src/app/links/[id]/page.tsx`
- インポート:
  - `../actions` から `updateLink`
  - `@/lib/prisma` から `prisma`
- `LinkDetailPage` コンポーネント:
  - `prisma.link.findUnique` を実行して `link` を取得。
    - オプション: `where: { id }`
  - 取得結果が存在しない場合、`notFound()` を実行。
  - `form` タグの `action` 属性に `updateLink` を設定。

【命名】
- なし

【参照】
- インポート識別子: `updateLink`, `prisma`

【使用タグ】
- `div`: 全体のラッパー。要素間に縦方向の余白を設ける。
  - `div`: フォームのコンテナー。角丸、枠線、背景色、パディングを設定。
    - `form`: 更新用フォーム。Flexboxで縦並びに配置。`action`属性に`updateLink`を設定。
      - `label`: タイトル入力欄のラベル。
        - `input`: テキスト入力。`name="title"`。
      - `label`: URL入力欄のラベル。
        - `input`: URL入力。`name="url"`。
      - `p`: 作成日時と更新日時を表示。
      - `div`: ボタン類のラッパー。
        - `button`: 更新ボタン。「更新する」を表示。
        - `a`: 外部リンク。「URLを開く」を表示。

### ヒント

- `LinkDetailPage` は `async` 関数である必要があります（すでにそうなっているはずです）。
- `prisma.link.findUnique` は `await` して結果を受け取ります。
- 使用クラス一覧:
  - `div（全体）`: `space-y-6`
  - `div（フォーム枠）`: `space-y-4`, `rounded-xl`, `border`, `bg-slate-900`, `p-6`
  - `form`: `flex`, `flex-col`, `gap-4`
  - `label`: `flex`, `flex-col`, `gap-2`, `text-sm`, `text-slate-100`
  - `input`: `rounded-lg`, `border`, `bg-slate-900`, `p-3`
  - `p`: `text-sm`, `text-slate-400`
  - `div（ボタン）`: `flex`, `flex-wrap`, `gap-3`
  - `button`: `rounded-lg`, `bg-emerald-400`, `px-5`, `py-2`, `text-slate-900`
  - `a`: `rounded-lg`, `border`, `px-5`, `py-2`, `text-white`

### 解答例

```tsx
import { notFound } from 'next/navigation';
import { updateLink } from '../actions';
import { prisma } from '@/lib/prisma';

// リンク詳細ページ
export default async function LinkDetailPage({ params }: { params: Promise<{ id: string }> }) {
  const id = Number((await params).id);
  if (!Number.isInteger(id)) {
    notFound();
  }

  const link = await prisma.link.findUnique({ where: { id } });
  if (!link) {
    notFound();
  }

  return (
    <div className="space-y-6">
      <div className="space-y-4 rounded-xl border bg-slate-900 p-6">
        <form className="flex flex-col gap-4" action={updateLink}>
          <label className="flex flex-col gap-2 text-sm text-slate-100">
            タイトル
            <input
              className="rounded-lg border bg-slate-900 p-3"
              type="text"
              name="title"
              defaultValue={link.title}
              required
            />
          </label>

          <label className="flex flex-col gap-2 text-sm text-slate-100">
            URL
            <input
              className="rounded-lg border bg-slate-900 p-3"
              type="url"
              name="url"
              defaultValue={link.url}
              required
            />
          </label>

          <p className="text-sm text-slate-400">
            作成: {link.createdAt.toLocaleString()} ／ 更新: {link.updatedAt.toLocaleString()}
          </p>

          <div className="flex flex-wrap gap-3">
            <button
              type="submit"
              name="id"
              value={link.id}
              className="rounded-lg bg-emerald-400 px-5 py-2 text-slate-900"
            >
              更新する
            </button>
            <a href={link.url} target="_blank" rel="noreferrer" className="rounded-lg border px-5 py-2 text-white">
              URLを開く
            </a>
          </div>
        </form>
      </div>
    </div>
  );
}
```
