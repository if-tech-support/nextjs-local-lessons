## はじめに
個別のリンク詳細を表示し、編集するためのページを作成します。Prisma Clientを使用してデータを取得し、Server Actionsを使って更新処理を実装します。

## 目的
- Dynamic Routes (`[id]`) を使用してURLパラメーターを受け取る
- Prisma ClientでIDに基づいたデータ取得を行う
- Server Actionsでデータの更新処理を行う

## 学習対象のスキル
- `prisma.link.findUnique`

## 課題A：Dynamic Routesとデータ取得（10分）

10分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。
まずはURLパラメーターからIDを取得し、データベースから該当するリンク情報を取得して表示します。

### 仕様

`src/app/links/[id]/page.tsx` を作成し、データ取得ロジックを実装します。

- 対象ファイル: `src/app/links/[id]/page.tsx`
- インポート:
  - `next/navigation` から `notFound`
  - `@/lib/prisma` から `prisma`
- `LinkDetailPage` コンポーネント:
  - デフォルトエクスポートされた非同期関数。
  - Props: `params`（Promise型）を受け取る。
  - 処理:
    1. `params` を `await` して `id` を取得する。
    2. `id` を数値に変換する。
    3. `prisma.link.findUnique` でデータを取得する（`where: { id: 数値ID }`）。
    4. データが存在しない場合は `notFound()` を実行する。
  - レンダリング:
    - 取得した `link.title` と `link.url` を単純な `div` や `p` タグで表示して確認する。

【命名】
- コンポーネント: `LinkDetailPage`

【参照】
- インポート識別子: `notFound`, `prisma`

### ヒント

- Next.js 15以降、`params` は`Promise`なので `await` が必要です。
- `prisma.link.findUnique` の `where` 条件には一意な識別子（ID）を指定します。

### 解答例

```tsx
import { notFound } from 'next/navigation';
import { prisma } from '@/lib/prisma';

export default async function LinkDetailPage({ params }: { params: Promise<{ id: string }> }) {
  const id = Number((await params).id);
  if (!Number.isInteger(id)) {
    notFound();
  }

  const link = await prisma.link.findUnique({ where: { id } });
  if (!link) {
    notFound();
  }

  return (
    <div>
      <h1>{link.title}</h1>
      <p>{link.url}</p>
    </div>
  );
}
```

## 課題B：編集フォームのUI作成（10分）

10分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。
取得したデータを初期値として表示する編集フォームのUIを作成します。

### 仕様

取得した `link` データを使用して、スタイリングされたフォームを作成します。

- UI構造:
  - `div`: 全体のラッパー。要素間に縦方向の余白を設ける。
    - `div`: フォームのコンテナー。角丸、枠線、背景色、パディングを設定。
      - `form`: 更新用フォーム。Flexboxで縦並びに配置。
        - `label`: タイトル入力欄のラベル。
          - `input`: テキスト入力。`name="title"`、`defaultValue`にタイトルを設定。
        - `label`: URL入力欄のラベル。
          - `input`: URL入力。`name="url"`、`defaultValue`にURLを設定。
        - `p`: 作成日時と更新日時を表示。
        - `div`: ボタン類のラッパー。
          - `button`: 更新ボタン。「更新する」を表示。
          - `a`: 外部リンク。「URLを開く」を表示。

【使用タグ】
- `div（全体）`: `space-y-6`
- `div（フォーム枠）`: `space-y-4`, `rounded-xl`, `border`, `bg-slate-900`, `p-6`
- `form`: `flex`, `flex-col`, `gap-4`
- `label`: `flex`, `flex-col`, `gap-2`, `text-sm`, `text-slate-100`
- `input`: `rounded-lg`, `border`, `bg-slate-900`, `p-3`
- `p`: `text-sm`, `text-slate-400`
- `div（ボタン）`: `flex`, `flex-wrap`, `gap-3`
- `button`: `rounded-lg`, `bg-emerald-400`, `px-5`, `py-2`, `text-slate-900`
- `a`: `rounded-lg`, `border`, `px-5`, `py-2`, `text-white`

### ヒント

- `input` の `defaultValue` 属性を使うと、初期値を設定しつつ編集可能なフィールドを作成できます。
- 日時は `link.createdAt.toLocaleString()` などでフォーマットして表示します。

### 解答例

```tsx
import { notFound } from 'next/navigation';
import { prisma } from '@/lib/prisma';

export default async function LinkDetailPage({ params }: { params: Promise<{ id: string }> }) {
  const id = Number((await params).id);
  if (!Number.isInteger(id)) {
    notFound();
  }

  const link = await prisma.link.findUnique({ where: { id } });
  if (!link) {
    notFound();
  }

  return (
    <div className="space-y-6">
      <div className="space-y-4 rounded-xl border bg-slate-900 p-6">
        <form className="flex flex-col gap-4">
          <label className="flex flex-col gap-2 text-sm text-slate-100">
            タイトル
            <input
              className="rounded-lg border bg-slate-900 p-3"
              type="text"
              name="title"
              defaultValue={link.title}
              required
            />
          </label>

          <label className="flex flex-col gap-2 text-sm text-slate-100">
            URL
            <input
              className="rounded-lg border bg-slate-900 p-3"
              type="url"
              name="url"
              defaultValue={link.url}
              required
            />
          </label>

          <p className="text-sm text-slate-400">
            作成: {link.createdAt.toLocaleString()} ／ 更新: {link.updatedAt.toLocaleString()}
          </p>

          <div className="flex flex-wrap gap-3">
            <button
              type="submit"
              className="rounded-lg bg-emerald-400 px-5 py-2 text-slate-900"
            >
              更新する
            </button>
            <a
              href={link.url}
              target="_blank"
              rel="noreferrer"
              className="rounded-lg border px-5 py-2 text-white"
            >
              URLを開く
            </a>
          </div>
        </form>
      </div>
    </div>
  );
}
```

## 課題C：更新機能の統合（5分）

5分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。
作成したフォームをServer Actionsに接続し、データの更新ができるようにします。

### 仕様

- インポート:
  - `../actions` から `updateLink` を追加。
- フォーム修正:
  - `form` タグの `action` 属性に `updateLink` を設定。
  - `button` タグに `name="id"` と `value={link.id}` を追加。

【参照】
- インポート識別子: `updateLink`

### ヒント

- 更新用のアクション `updateLink` は前章で作成済みです。
- ボタンに `name` と `value` 属性を付けることで、フォーム送信時にIDを含められます。

### 解答例

```tsx
import { notFound } from 'next/navigation';
import { updateLink } from '../actions';
import { prisma } from '@/lib/prisma';

// リンク詳細ページ
export default async function LinkDetailPage({ params }: { params: Promise<{ id: string }> }) {
  const id = Number((await params).id);
  if (!Number.isInteger(id)) {
    notFound();
  }

  const link = await prisma.link.findUnique({ where: { id } });
  if (!link) {
    notFound();
  }

  return (
    <div className="space-y-6">
      <div className="space-y-4 rounded-xl border bg-slate-900 p-6">
        <form className="flex flex-col gap-4" action={updateLink}>
          <label className="flex flex-col gap-2 text-sm text-slate-100">
            タイトル
            <input
              className="rounded-lg border bg-slate-900 p-3"
              type="text"
              name="title"
              defaultValue={link.title}
              required
            />
          </label>

          <label className="flex flex-col gap-2 text-sm text-slate-100">
            URL
            <input
              className="rounded-lg border bg-slate-900 p-3"
              type="url"
              name="url"
              defaultValue={link.url}
              required
            />
          </label>

          <p className="text-sm text-slate-400">
            作成: {link.createdAt.toLocaleString()} ／ 更新: {link.updatedAt.toLocaleString()}
          </p>

          <div className="flex flex-wrap gap-3">
            <button
              type="submit"
              name="id"
              value={link.id}
              className="rounded-lg bg-emerald-400 px-5 py-2 text-slate-900"
            >
              更新する
            </button>
            <a href={link.url} target="_blank" rel="noreferrer" className="rounded-lg border px-5 py-2 text-white">
              URLを開く
            </a>
          </div>
        </form>
      </div>
    </div>
  );
}
```
