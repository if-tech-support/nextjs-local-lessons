## はじめに
一覧ページから不要なリンクを削除する機能を実装します。これでCRUD（作成・読み取り・更新・削除）のすべての機能が揃います。

## 目的
- Server Actionsでデータの削除処理を実装する
- Prisma Clientでデータを削除する (`delete`)
- 削除後に一覧ページを更新する

## 学習対象のスキル
- `prisma.link.delete`

## 課題A：削除用Server Actionsを作成する（10分）

10分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

削除用Server Actionsを`src/app/links/actions.ts`に追加します。

- 対象ファイル: `src/app/links/actions.ts`
- アクション関数 `deleteLink(formData: FormData)` を追加する（エクスポート）。
  - `formData` から `id` を取得し、`parseNumericId` で検証。
  - `prisma.link.delete` でデータを削除。
    - `where`: `{ id }`
  - `revalidatePath(LINKS_PATH)` を実行。
  - `redirect(LINKS_PATH)` を実行。

【命名】
- `deleteLink`

【参照】
- `prisma`
- `parseNumericId`
- `revalidatePath`
- `redirect`
- `LINKS_PATH`

【使用タグ】
- （該当なし）

### ヒント

- 削除処理は取り消しができないため、慎重に実装する必要があります（今回は確認ダイアログ等は省略します）。

### 解答例

```typescript
// src/app/links/actions.ts の追記部分

// ...既存のコード...

// リストアイテムの削除アクション。パスを再検証して一覧へ戻る
export async function deleteLink(formData: FormData) {
  const id = parseNumericId(formData.get('id'));

  await prisma.link.delete({ where: { id } });

  revalidatePath(LINKS_PATH);
  redirect(LINKS_PATH);
}
```
