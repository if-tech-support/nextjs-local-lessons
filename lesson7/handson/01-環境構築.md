## はじめに
本ハンズオンでは、Next.jsとSupabase、Prismaを組み合わせたアプリケーション開発の環境を作ります。
Next.jsプロジェクトを新規作成し、Supabaseのローカル環境を起動して、Prismaを使用するための設定まで完了させます。

## 目的
- Next.jsプロジェクトを新規作成する
- Supabaseローカルデータベースを起動する
- PrismaとPostgreSQLドライバーをインストールし設定する

## 前提環境
- Node.js v18以上
- Docker Desktop（Supabaseローカル環境用）

## 学習対象のスキル
- Prisma CLI
- `prisma.config.ts`

## 手順1: プロジェクトの作成（5分）
1. ターミナルで作業ディレクトリに移動し、以下のコマンドを実行して新規プロジェクトを作成します。
   ```bash
   npx create-next-app@latest nextjs-prisma-app --typescript --eslint --tailwind --src-dir --app --import-alias "@/*" --use-npm
   ```
   - 質問が表示された場合はすべてデフォルト（Enterキー）で進めます。

2. 作成されたディレクトリに移動します。
   ```bash
   cd nextjs-prisma-app
   ```

3. 開発サーバーを起動し、動作を確認します。
   ```bash
   npm run dev
   ```
   - ブラウザで `http://localhost:3000` にアクセスし、Next.jsの初期画面が表示されることを確認します。
   - 確認ができたら `Ctrl+C` でサーバーを停止します。

## 手順2: Supabaseのセットアップと起動（10分）
1. Supabase CLIを開発用依存関係としてインストールします。
   ```bash
   npm install -D supabase
   ```

2. Supabaseを初期化します。
   ```bash
   npx supabase init
   ```
   - これにより `supabase` ディレクトリが生成されます。

3. Supabaseのローカル環境を起動します。
   ```bash
   npx supabase start
   ```
   - 初回起動時はDockerイメージのダウンロードに時間がかかる場合があります。

4. 起動後に表示される出力の中から `DB URL` の値をコピーして控えておきます（後で使用します）。
   - 例: `postgresql://postgres:postgres@127.0.0.1:54322/postgres`

## 手順3: パッケージのインストール（5分）
1. Prisma CLIと開発用ツールをインストールします。
   ```bash
   npm install -D prisma ts-node @types/node
   ```
2. Prisma ClientとPostgreSQL用のアダプター、環境変数管理ライブラリをインストールします。
   ```bash
   npm install @prisma/client @prisma/adapter-pg pg dotenv
   ```

## 手順4: Prismaの初期化と設定（10分）
1. 以下のコマンドを実行して、Prismaを初期化します。
   ```bash
   npx prisma init
   ```
   - これにより `prisma` ディレクトリと `.env` ファイルが生成されます。

2. プロジェクトルートの `.env` ファイルを開き、`DATABASE_URL` の値を手順2で控えた `DB URL` に書き換えます。
   ```env
   DATABASE_URL="postgresql://postgres:postgres@127.0.0.1:54322/postgres"
   ```
   ※ ポート番号（例: `54322`）は環境によって異なる場合があります。必ず自分の環境の `DB URL` を使用してください。

3. プロジェクトルートに `prisma.config.ts` を作成し、以下の内容を記述します。
   - これにより、Prismaの設定をTypeScriptファイルで管理できるようになります。

   ```ts
   // This file was generated by Prisma, and assumes you have installed the following:
   // npm install --save-dev prisma dotenv
   import "dotenv/config";
   import { defineConfig } from "prisma/config";

   export default defineConfig({
     schema: "prisma/schema.prisma",
     migrations: {
       path: "prisma/migrations",
     },
     datasource: {
       url: process.env["DATABASE_URL"],
     },
   });
   ```

## 章末の確認

確認ポイント（結果が得られればOK）
- Next.js起動: `http://localhost:3000` が表示される
- Supabaseコンテナー起動: `npx supabase status` で `running` 状態
- Prisma CLI動作: `npx prisma --version` でバージョン表示
- 設定ファイル生成: `prisma.config.ts` が存在
- 環境変数設定: `.env` の `DATABASE_URL` がローカルDBを指している

コマンド（一例）
```bash
npx supabase status
npx prisma --version
ls prisma.config.ts
cat .env
```
