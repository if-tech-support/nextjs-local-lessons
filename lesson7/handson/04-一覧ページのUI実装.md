## はじめに
アプリケーションの共通レイアウトを作成し、リンク一覧ページのUIを実装します。まずは静的なマークアップを行い、次章でデータベースと接続します。

## 目的
- アプリケーション全体のレイアウト（ヘッダー、メインエリア）を定義する
- トップページから一覧ページへのリダイレクトを設定する
- 一覧ページに新規作成フォームとリンクリストのUIを実装する

## 課題A：共通レイアウトとトップページ（10分）

10分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

`src/app/layout.tsx` を編集して共通デザインを適用し、`src/app/page.tsx` でリダイレクトを設定します。

- 対象ファイル: `src/app/layout.tsx`
  - メタデータ: タイトルを「リンクスタジオ」、説明を「ブックマークを保存して管理するアプリケーション」に設定。
  - フォント: `next/font/google` から `Geist`, `Geist_Mono` を読み込み、変数 `geistSans`, `geistMono` を定義（`variable` オプションを設定）。
  - `body`: 背景色（スレート950）、文字色（スレート100）、フォント変数をクラスに適用。

- 対象ファイル: `src/app/page.tsx`
  - `next/navigation` から `redirect` をインポート。
  - コンポーネント内で `redirect('/links')` を実行し、ルートアクセス時に `/links` へ転送する。

【使用タグ】
- `html`
  - `body`: 背景色と文字色を設定。
    - `div`: 画面全体のラッパー。最小高さを画面いっぱいに設定。
      - `header`: ヘッダー領域。背景色と下線を設定。
        - `div`: 幅制御コンテナー。最大幅を設定し中央寄せ。パディングを設定。
          - `div`: Flexboxコンテナー。要素を両端揃えにする。
            - `Link`: アプリタイトル。「リンクスタジオ」を表示し、`/links`へ遷移。文字サイズを大きくし太字にする。
      - `main`: メインコンテンツ領域。最大幅を設定し中央寄せ。パディングを設定。
        - `children`: ページコンテンツをレンダリング。

【命名】
- コンポーネント: `RootLayout`, `Home`
- 変数: `geistSans`, `geistMono`

【参照】
- インポート識別子: `Metadata`, `Link`, `Geist`, `Geist_Mono`, `redirect`

### ヒント

- 使用クラス一覧:
  - `body`: `bg-slate-950`, `text-slate-100`
  - `div（ラッパー）`: `min-h-screen`
  - `header`: `border-b`, `border-slate-800`, `bg-slate-950`
  - `div（ヘッダー内部）`: `mx-auto`, `max-w-4xl`, `px-4`, `py-4`
  - `div（Flexコンテナー）`: `flex`, `items-center`, `justify-between`, `gap-4`
  - `Link（タイトル）`: `text-lg`, `font-semibold`, `text-white`
  - `main`: `mx-auto`, `max-w-4xl`, `px-4`, `py-8`
- `layout.tsx` の `body` クラスには `${geistSans.variable} ${geistMono.variable}` を含めます。
- `redirect` 関数はサーバーコンポーネント内で直接呼び出すことができます。

### 解答例

```tsx
// src/app/layout.tsx
import type { Metadata } from 'next';
import Link from 'next/link';
import { Geist, Geist_Mono } from 'next/font/google';
import './globals.css';

const geistSans = Geist({
  variable: '--font-geist-sans',
  subsets: ['latin'],
});

const geistMono = Geist_Mono({
  variable: '--font-geist-mono',
  subsets: ['latin'],
});

export const metadata: Metadata = {
  title: 'リンクスタジオ',
  description: 'ブックマークを保存して管理するアプリケーション',
};

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html lang="ja">
      <body className={`${geistSans.variable} ${geistMono.variable} bg-slate-950 text-slate-100`}>
        <div className="min-h-screen">
          <header className="border-b border-slate-800 bg-slate-950">
            <div className="mx-auto max-w-4xl px-4 py-4">
              <div className="flex items-center justify-between gap-4">
                <Link href="/links" className="text-lg font-semibold text-white">
                  リンクスタジオ
                </Link>
              </div>
            </div>
          </header>
          <main className="mx-auto max-w-4xl px-4 py-8">{children}</main>
        </div>
      </body>
    </html>
  );
}
```

```tsx
// src/app/page.tsx
import { redirect } from 'next/navigation';

// ルートアクセス時は即座にリンク一覧へ誘導する
export default function Home() {
  redirect('/links');
}
```

## 課題B：一覧ページのUI作成（15分）

15分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

`src/app/links/page.tsx` を作成し、新規作成フォームと一覧表示のUIを実装します。データは一時的にダミーデータを使用します。

- 対象ファイル: `src/app/links/page.tsx`
- コンポーネント: `LinksPage`（非同期関数 `async` 推奨）
- ダミーデータ: `links` 配列を定義（例: `[{ id: 1, title: 'Example', url: 'https://example.com' }]`）。

【使用タグ】
- `div`: ページ全体のラッパー。要素間の垂直間隔を設定。
  - `div`: 新規作成フォームのコンテナー。角丸、枠線、背景色を設定。
    - `h1`: 見出し。`リンクを保存する`を表示。
    - `form`: 入力フォーム。グリッドレイアウトを使用。
      - `label`: タイトル入力用ラベル。Flexboxで縦並びにする。
        - テキスト`タイトル`
        - `input`: テキスト入力欄。角丸、枠線、背景色を設定。
      - `label`: URL入力用ラベル。Flexboxで縦並びにする。
        - テキスト`URL`
        - `input`: URL入力欄。角丸、枠線、背景色を設定。
      - `button`: 送信ボタン。「追加する」を表示。背景色を設定。
  - `div`: 一覧表示のコンテナー。要素間の垂直間隔を設定。
    - `h2`: 見出し。「保存済みリンク」を表示。
    - `p`: データが空の場合のメッセージ。`まだ登録がありません...`を表示。角丸、枠線、背景色を設定。
    - `ul`: リスト表示。要素間の垂直間隔を設定。
      - `li`: 各リンクアイテム。角丸、枠線、背景色を設定。
        - `a`: 外部リンク。タイトルを表示。太字にする。
        - `p`: URLを表示。文字色を薄くする。
        - `div`: アクションボタンのコンテナー。Flexboxで横並びにする。
          - `Link`: 詳細ページへのリンク。`詳細`を表示。枠線付きボタン風スタイル。
          - `form`: 削除用フォーム。
            - `input`: 隠しフィールド（ID用）。
            - `button`: 削除ボタン。`削除`を表示。赤文字の枠線付きボタン風スタイル。

【命名】
- コンポーネント: `LinksPage`
- 変数: `links`

【参照】
- インポート識別子: `Link`

### ヒント

- 使用クラス一覧:
  - `div（全体ラッパー）`: `space-y-8`
  - `div（フォームコンテナー）`: `space-y-4`, `rounded-xl`, `border`, `bg-slate-900`, `p-6`
  - `h1`: `text-2xl`, `font-semibold`, `text-white`
  - `form`: `mt-4`, `grid`, `gap-4`, `md:grid-cols-2`
  - `label`: `flex`, `flex-col`, `gap-2`, `text-sm`, `text-slate-100`
  - `input`: `rounded-lg`, `border`, `bg-slate-900`, `p-3`
  - `button（追加）`: `rounded-lg`, `bg-emerald-400`, `py-2`, `text-slate-900`, `md:col-span-2`
  - `div（リストコンテナー）`: `space-y-2`
  - `h2`: `text-lg`, `font-semibold`, `text-white`
  - `p（空メッセージ）`: `rounded-xl`, `border`, `bg-slate-900`, `p-5`, `text-center`
  - `ul`: `space-y-4`
  - `li`: `space-y-3`, `rounded-xl`, `border`, `bg-slate-900`, `p-5`
  - `a（リンクタイトル）`: `text-lg`, `font-semibold`, `text-white`
  - `p（URL）`: `text-sm`, `text-slate-400`
  - `div（ボタンラッパー）`: `flex`, `flex-wrap`, `gap-3`
  - `Link（詳細）`: `rounded-lg`, `border`, `px-4`, `py-2`, `text-white`
  - `button（削除）`: `rounded-lg`, `border`, `px-4`, `py-2`, `text-red-200`
- `form` の `action` 属性は次章で設定するため、現時点では省略して構いません。
- ダミーデータを使ってリスト表示のスタイルを確認してください。

### 解答例

```tsx
import Link from 'next/link';

// リンク一覧ページ
export default async function LinksPage() {
  // ダミーデータ（次章でDB取得に置き換えます）
  const links = [
    {
      id: 1,
      title: 'Example',
      url: 'https://example.com',
      createdAt: new Date(),
      updatedAt: new Date(),
    },
  ];

  return (
    <div className="space-y-8">
      <div className="space-y-4 rounded-xl border bg-slate-900 p-6">
        <h1 className="text-2xl font-semibold text-white">リンクを保存する</h1>

        <form className="mt-4 grid gap-4 md:grid-cols-2">
          <label className="flex flex-col gap-2 text-sm text-slate-100">
            タイトル
            <input
              className="rounded-lg border bg-slate-900 p-3"
              type="text"
              name="title"
              placeholder="タイトルを入力"
              required
            />
          </label>
          <label className="flex flex-col gap-2 text-slate-100 md:col-span-2">
            URL
            <input
              className="rounded-lg border bg-slate-900 p-3"
              type="url"
              name="url"
              placeholder="https://example.com"
              required
            />
          </label>
          <button type="submit" className="rounded-lg bg-emerald-400 py-2 text-slate-900 md:col-span-2">
            追加する
          </button>
        </form>
      </div>

      <div className="space-y-2">
        <h2 className="text-lg font-semibold text-white">保存済みリンク</h2>
        {links.length === 0 ? (
          <p className="rounded-xl border bg-slate-900 p-5 text-center">
            まだ登録がありません。上のフォームから追加してください。
          </p>
        ) : (
          <ul className="space-y-4">
            {links.map((link) => {
              return (
                <li key={link.id} className="space-y-3 rounded-xl border bg-slate-900 p-5">
                  <a href={link.url} target="_blank" rel="noreferrer" className="text-lg font-semibold text-white">
                    {link.title}
                  </a>
                  <p className="text-sm text-slate-400">{link.url}</p>
                  <div className="flex flex-wrap gap-3">
                    <Link href={`/links/${link.id}`} className="rounded-lg border px-4 py-2 text-white">
                      詳細
                    </Link>
                    <form>
                      <input type="hidden" name="id" value={link.id} />
                      <button type="submit" className="rounded-lg border px-4 py-2 text-red-200">
                        削除
                      </button>
                    </form>
                  </div>
                </li>
              );
            })}
          </ul>
        )}
      </div>
    </div>
  );
}
```
