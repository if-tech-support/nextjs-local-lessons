## はじめに
Prisma Schemaファイルにデータモデルを定義し、マイグレーションを実行してデータベースにテーブルを作成します。

## 目的
- Prisma Schemaでモデルを定義する
- マイグレーションを実行してDBスキーマを更新する
- 生成されたPrisma Clientの出力先を確認する

## 学習対象のスキル
- `schema.prisma`
- マイグレーション

## 課題A：スキーマを定義する（10分）

10分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

- `npx prisma init` で生成済みの `prisma/schema.prisma` を編集し、Prisma Clientの出力先設定と `Link` モデルの定義を行います。
- 対象ファイル: `prisma/schema.prisma`

- 既存の `generator client` ブロック
  - `output` オプションを追加し、`../src/generated/prisma` を指定する。
- 既存の `datasource db` ブロック
  - `url` の設定行を削除する（`prisma.config.ts` で設定しているため）。
- `model Link` ブロック（新規追加）
  - 以下のフィールドを持つモデルを定義する。
  - `id`: Int型、`@id`、`@default(autoincrement())`。
  - `title`: String型。
  - `url`: String型。
  - `createdAt`: DateTime型、`@default(now())`。
  - `updatedAt`: DateTime型、`@updatedAt`。
  - モデルの上にコメント `// Link bookmarks exposed to Next.js Server Actions` を記述する。

【命名】
- モデル: `Link`
- フィールド: `id`, `title`, `url`, `createdAt`, `updatedAt`

【使用タグ】
- （該当なし）

### ヒント

- `datasource` ブロックから `url = env("DATABASE_URL")` を削除することを忘れないでください。
- `generator` ブロックの `output` は相対パスで指定します。

### 解答例

```prisma
// This is your Prisma schema file,
// learn more about it in the docs: https://pris.ly/d/prisma-schema

// Looking for ways to speed up your queries, or scale easily with your serverless or edge functions?
// Try Prisma Accelerate: https://pris.ly/cli/accelerate-init

generator client {
  provider = "prisma-client"
  output   = "../src/generated/prisma"
}

datasource db {
  provider = "postgresql"
}

// Link bookmarks exposed to Next.js Server Actions
model Link {
  id        Int        @id @default(autoincrement())
  title     String
  url       String
  createdAt DateTime   @default(now())
  updatedAt DateTime   @updatedAt
}
```

## 課題B：マイグレーションを実行する（5分）

5分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

- 定義したスキーマをデータベースに反映させるために、マイグレーションを実行します。
- 対象ファイル: ターミナル

- ターミナルで `prisma migrate dev` コマンドを実行する。
- マイグレーション名は `init` とする。

【命名】
- マイグレーション名: `init`

【使用タグ】
- （該当なし）

### ヒント

- コマンド: `npx prisma migrate dev --name <マイグレーション名>`

### 解答例

```bash
npx prisma migrate dev --name init
```

## 章末の確認

- ブラウザでSupabase Studio (http://127.0.0.1:54323) にアクセスします。
- 左側のメニューから「Table Editor」を選択し、`Link` テーブルが作成されていることを確認します。
- `Link` テーブルのカラム（`id`, `title`, `url`, `createdAt`, `updatedAt`）が正しく定義されていることを確認します。
