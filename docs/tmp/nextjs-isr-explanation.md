# Next.jsのISR（インクリメンタル静的再生成）について

## 概要
ISR（Incremental Static Regeneration）とは、SSG（静的サイト生成）の「速さ」と、SSR（サーバーサイドレンダリング）の「情報の新しさ」をいいとこ取りした仕組みです。

基本的にはSSGのようにあらかじめページを作っておきますが、設定した時間が経過すると、裏側で自動的に新しいページを作り直してくれます。

例えるなら、「定期的に焼き上がるパン屋さん」のようなものです。
- **SSG**: 朝一番に焼いたパンを、閉店まで売り続ける。
- **SSR**: お客さんが来るたびに、その場でパンを焼く。
- **ISR**: 朝一番にパンを焼くが、例えば「1時間ごと」に新しいパンを焼き直して、棚の商品を入れ替える。

これにより、高速に表示しつつ、ある程度新しい情報をユーザーに届けることができます。

## 特徴
ISRには主に2つのメリットがあります。

1. **高速な表示を維持できる**
   基本は作っておいたHTMLを返すだけなので、SSGと同じように非常に高速です。

2. **定期的に内容を更新できる**
   SSGでは一度ビルドすると次のビルドまで内容が変わりませんが、ISRなら設定した時間ごとに自動で最新データを取り込んでページを更新できます。

ブログのトップページや、商品一覧ページなど、「リアルタイムである必要はないが、定期的に最新情報に更新したい」場合に最適です。

## 使い方
`fetch` 関数を使ってデータを取得する際に、`next` オプションの `revalidate` に秒数を指定することでISRになります。

```typescript
// 3600秒（1時間）ごとにデータを再取得してページを作り直す（ISRの挙動）
const res = await fetch('https://api.example.com/news', {
  next: { revalidate: 3600 }
});
```

この設定をすると、最初のアクセスから3600秒間は同じページが表示されますが、それ以降に誰かがアクセスすると、裏側で新しいデータを取得してページが更新されます。
