# schema.prisma とは

## 概要
`schema.prisma` は、Prismaを使用するプロジェクトにおいて、データベースの構造を定義するための「設計図」となるファイルです。

家を建てるときに設計図が必要なように、アプリケーションでデータを保存するためには、どのようなデータをどのような形式で保存するかを決めておく必要があります。`schema.prisma` にその設計図を記述することで、Prismaがデータベースを構築したり、プログラムからデータを扱いやすくしたりしてくれます。

## 特徴

### 1. 人間が読み書きしやすい
データベースを操作するための専門的な言語（SQLなど）を詳しく知らなくても、直感的な書き方でデータの構造を定義できます。

### 2. すべての中心となるファイル
すでに学習した `Prisma CLI` は、この `schema.prisma` ファイルの内容を読み取って動作します。
たとえば、「データベースにテーブルを作成する」「プログラムで使うためのコードを生成する」といった操作は、すべてこのファイルに書かれた内容をもとに行われます。

### 3. 1つのファイルで完結する
データベースの設定や、データの形（モデル）の定義など、必要な情報は基本的にこの1つのファイルにまとめて記述します。そのため、どこに何が書いてあるかが分かりやすく、管理が簡単です。

## 使い方
`schema.prisma` ファイルには、主に以下の3つの要素を記述します。

### 1. データソースの定義 (`datasource`)
どの種類のデータベース（PostgreSQL, MySQL, SQLiteなど）を使うか、そしてそのデータベースがどこにあるか（接続先URL）を指定します。

### 2. ジェネレーターの定義 (`generator`)
Prismaがどのようなツール（クライアント）を生成するかを指定します。通常は、JavaScriptやTypeScriptからデータベースを操作するための `Prisma Client` を生成する設定を書きます。

### 3. モデルの定義 (`model`)
これがもっとも重要な部分です。アプリケーションで扱うデータの形（ユーザー、記事、商品など）を定義します。

以下は、ユーザー（User）というデータを定義する場合の記述例です。

```prisma
// データベースの接続設定
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

// クライアント生成の設定
generator client {
  provider = "prisma-client-js"
}

// ユーザーモデルの定義
model User {
  id    Int     @id @default(autoincrement()) // ユーザーID（自動で番号が振られる）
  email String  @unique                       // メールアドレス（重複不可）
  name  String?                               // 名前（省略可能）
}
```

このように記述するだけで、「ID、メールアドレス、名前を持つユーザー」というデータの構造をPrismaに伝えることができます。あとは `Prisma CLI` を使って、この設計図通りにデータベースを作成できます。
