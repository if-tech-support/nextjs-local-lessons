# lesson4 handson記事の【使用タグ】整形＆スタイル記述削除プロンプト

次の方針のみで、対象Markdownをファイル単位に順次処理してください。

## 目的
- 【使用タグ】: DOM/JSX階層がわかるように親子の全タグを列挙する。その上で、同レッスン内の先行章（本章より前のすべての章）と比較した差分に応じ、以下の形式で記載する。
  -（新規）`<タグ>`: 本章で新たに登場したタグ。新規クラスに対応するスタイルの日本語の説明のみを記載
  -（変更）`<タグ>`: 既存タグでクラスの追加/変更があるもの。新規/変更クラスに対応するスタイルの日本語の説明のみを記載
  - `<タグ>`: 差分のないタグ（階層維持のため列挙。スタイル説明は書かない）
- 【使用タグ】と「ヒント」以外（例: 仕様、章末の確認など）の本文から、スタイルに関する記述を削除する。コードブロック（解答例のコード）は変更しない。

## 対象ファイル
- グロブ: `lesson4/handson/[0-9]*-*.md`
- 1ファイルずつ独立して処理し、内容を上書き保存する。

## 作業手順
1) セクション検出
- 見出しやラベルで区切られる以下のセクションを特定:
  - 「【使用タグ】」ブロック
  - 「### 仕様」
  - 「### ヒント」
  - 「### 解答例」（コードブロックを含む）
  - 「章末の確認」（あれば）
- セクションの順序やその他の本文は極力保持し、不要な改行や空白の差分は最小化する。

2) 差分比較の準備（先行章ベース抽出）
- 同レッスン内の先行章（本章より前のすべての章）の同一UIの「### 解答例」コードから、タグごとのclassNameトークン一覧を抽出し、ベース集合（和集合）とする。
- タグ一致の目安: 同じ役割/同じ親子パス（header直下のdiv、footer直下のdiv、main、html、body、Linkなど）。

3) 【使用タグ】の再構成（階層全列挙＋差分マーキング）
- 現在章の「### 解答例」コードを解析し、各タグのclassNameをトークン化して前章ベースと比較する。
- DOM/JSX階層をインデントで表し、親子の全タグを列挙する。
- タグごとの表記ルール:
  -（新規）`<タグ>`: 新規に追加されたタグ。
  -（変更）`<タグ>`: クラスの追加または変更がある既存タグ。
  - `<タグ>`: 差分のないタグ（スタイル説明は書かない）。
- スタイル説明は、新規/変更クラスに対応する分だけを書く。前章と同一のクラスに由来する説明は書かない。
- 解答例にない情報は推測で追記しない。
- 解答例が複数ある場合は、対象UI（ヘッダー/フッター/レイアウトなど）に直接該当する主要なコードブロックのみ採用。
- 解答例が存在しない課題は、既存の【使用タグ】を維持（書き換えない）。

4) スタイル記述の削除（【使用タグ】とヒント以外）
- 以下のセクションから「スタイルに関する記述」を削除（行ごと削除）。構造や要件の説明は残す。
  - 「### 仕様」
  - 「章末の確認」
  - その他補足や本文（ヒントと解答例を除く）
- 削除対象の例:
  - Tailwindクラス名や具体値（例: `w-full sticky top-0 ...`）
  - 色/背景/文字色/余白/マージン/パディング/幅・高さ/最大幅/位置固定/重なり順/フォント/アイコン/アニメーション等のUI指定
  - 「〜のクラスを付与」「〜色にする」「〜pxの余白」等の見た目の指定
- 残すもの:
  - 「### ヒント」に含まれるスタイル関連のTipsやTailwind例（学習補助のため残す）
  - 「### 解答例」のコードブロック（コードは変更しない）
  - 機能・ナビゲーション・文言などの構造・要件説明
  - 「除外（今回未実装）」の列挙

5) ヒントの調整（クラス一覧化）
- 既存の汎用的なTailwind例は削除し、今回【使用タグ】に記載したスタイル説明に対応する「新規クラスのみ」を箇条書きで列挙する。
- フォーマット例:
  - 使用クラス一覧:
    - header: ...
    - div（header内）: ...
    - Link: ...
- 非スタイル系のTipsがヒント内にあれば保持してよい。

6) 最小編集の原則
- 文章の意味が変わらない範囲で行単位の削除に留める。残す行の語尾・句読点は変えない。
- 見出し・項目の順序は維持。
- コードブロックは一切編集不可。

## 出力
- 修正後のMarkdownをそのまま上書き保存可能な形で出力。追加の説明文や差分注釈は不要。

## 検収チェックリスト
- 【使用タグ】はDOM/JSX階層を維持して親子の全タグを列挙し、「（新規）/（変更）/無印」を正しく付与している。説明は新規/変更クラスに対応するもののみで、差分のないタグには説明を書いていない。
- 【使用タグ】の内容は、同一課題の「解答例」コードに基づいている（ない場合は既存のまま）。
- ヒントに新規クラスの一覧が列挙されている。
 - 「### 仕様」「章末の確認」などからスタイル記述が削除されている。
- 「### ヒント」と「### 解答例（コード）」は改変されていない。
- 文書構造（見出し・順序）は保持されている。
