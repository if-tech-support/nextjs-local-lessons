# Prisma CLIについて

## 概要

Prisma CLI（プリズマ シーエルアイ）は、Prismaを便利に使うための「司令塔」のようなツールです。

Prisma自体はデータベースとの通訳を行ってくれる便利な仕組みですが、そのPrismaに対して「データベースを作って」「設定ファイルを準備して」「データの中身を見せて」といった具体的な命令を出すために使うのが、このPrisma CLIです。

パソコンの黒い画面（ターミナル）にコマンド（命令文）を打ち込むことで、Prismaの色々な機能を動かすことができます。

## 特徴

Prisma CLIを使うと、主に以下のようなことができます。

*   **環境の準備**: Prismaを使い始めるために必要なファイルや設定を自動で作ってくれます。
*   **データベースの更新**: `schema.prisma` に書いた設計図の内容を、実際のデータベースに反映させることができます。これを「マイグレーション」と呼びます。
*   **データの確認**: データベースに入っているデータを、ブラウザ上で見やすく表示して管理する画面を立ち上げることができます。

## 使い方

ターミナルで `npx prisma` の後に命令を続けることで使用します。ここではよく使うコマンドをいくつか紹介します。

### 1. 初期設定をする

Prismaを使い始めるときに最初に行うコマンドです。必要なファイルを作成してくれます。

```bash
npx prisma init
```

### 2. データベースに変更を反映する

`schema.prisma`（設計図）を書き換えたあとに、その変更を実際のデータベースに適用するためのコマンドです。開発中は頻繁に使います。

```bash
npx prisma migrate dev
```

### 3. データベースの中身を見る

データベースに保存されているデータを、Webブラウザのような画面で確認・編集できるツール（Prisma Studio）を起動します。

```bash
npx prisma studio
```

### 4. プログラム用の道具を更新する

データベースの形が変わったときに、プログラムからデータベースを操作するための道具（Prisma Client）を最新の状態に更新します。通常は `migrate dev` をすると自動で行われますが、手動で行うこともあります。

```bash
npx prisma generate
```
