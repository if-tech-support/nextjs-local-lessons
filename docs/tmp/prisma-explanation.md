# Prismaについて

## 概要

Prisma（プリズマ）とは、Webアプリケーションとデータベースの間に入って、データのやり取りを仲介してくれる便利なツールです。専門用語では「ORM（オーアールエム）」と呼ばれることもあります。

例えるなら、**「優秀な通訳さん」**のような存在です。

通常、データベースと会話をするには「SQL」という専用の難しい言語を使う必要があります。しかし、Prismaという通訳さんがいれば、私たちは普段使っているプログラミング言語（JavaScriptやTypeScriptなど）で「データを保存して」「このデータを探して」と指示を出すだけで済みます。あとはPrismaがデータベースに伝わる言葉に自動で翻訳してくれます。

## 特徴

Prismaには以下のような特徴があり、開発を強力にサポートしてくれます。

*   **うっかりミスを防いでくれる**: コードを書いている最中に、「そのデータは存在しないよ」や「データの形が間違っているよ」と教えてくれる機能があります（型安全性）。これにより、プログラムを動かす前にミスに気づくことができます。
*   **直感的に書ける**: 複雑なデータベースの命令文を覚える必要がありません。「ユーザーを探す」「記事を作る」といった直感的な書き方で操作できるため、初心者でも扱いやすいです。
*   **設計図が見やすい**: `schema.prisma` という1つのファイルに、「どんなデータを保存するか」という設計図をまとめて書きます。これを見るだけで、データベースの中身がどうなっているかがひと目で分かります。

## 使い方

Prismaを使ってデータベースを操作するまでの大まかな流れは以下のとおりです。

1.  **インストール**: プロジェクトにPrismaを導入します。
2.  **設計図を書く**: `schema.prisma` というファイルに、保存したいデータの形（モデル）を定義します。
3.  **データベースに反映**: 書いた設計図を元に、実際のデータベースを作成・更新します（これを「マイグレーション」と呼びます）。
4.  **コードで使う**: 自動で作られる便利な道具（Prisma Client）を使って、データの読み書きを行います。

### コード例

まず、`schema.prisma` にデータの設計図を書きます。ここでは例として「ユーザー（User）」というデータを作る場合を見てみましょう。

```prisma
// schema.prisma

// ユーザーのモデル（設計図）
model User {
  id    Int     @id @default(autoincrement()) // ID（自動で番号が振られる）
  email String  @unique                       // メールアドレス（重複不可）
  name  String?                               // 名前（なくてもOK）
}
```

次に、プログラムの中で実際にデータを作成したり探したりするコードです。

```ts
import { PrismaClient } from '@prisma/client'

const prisma = new PrismaClient()

async function main() {
  // 新しいユーザーを作成する
  const newUser = await prisma.user.create({
    data: {
      email: 'alice@example.com',
      name: 'Alice',
    },
  })

  // 全てのユーザーを取得する
  const allUsers = await prisma.user.findMany()
}
```

このように、`prisma.user.create`（ユーザーを作る）や `prisma.user.findMany`（ユーザーをたくさん探す）といった、読みやすい言葉でデータベースを操作できます。
