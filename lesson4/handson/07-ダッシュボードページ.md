## はじめに

認証済みユーザーのみがアクセスできるダッシュボードページを作成する。サーバーコンポーネントで認証状態を確認し、未認証ユーザーをリダイレクトする保護機能を実装する。

## 目的

- サーバーコンポーネントでの認証ガードを実装する
- 取得したユーザー情報を画面に表示する
- Server Actionsを使用したログアウト機能を実装する

## 学習対象のスキル

- `supabase.auth.getUser()`によるセッション検証
- `redirect`関数によるページ遷移

## 課題A：認証ガードの実装（10分）

10分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

サーバーコンポーネントで認証状態を確認し、未認証ユーザーをリダイレクトすることで、認証済みユーザーのみがアクセスできるダッシュボードページを作成する。

- 対象ファイル: `src/app/dashboard/page.tsx`
- コンポーネント: `DashboardPage` (default export, async function)
- 処理フロー:
  - `createClient`（`@/lib/supabase/server`）を呼び出し、Supabaseクライアントインスタンスを作成する。
  - `supabase.auth.getUser()`を実行し、現在のユーザーセッション情報を取得する。
    - 戻り値から `data: { user }` と `error` を分割代入で取得する。
  - 認証チェックを行う。
    - `error` が存在するか、または `user` が `null` の場合、未認証とみなす。
    - 未認証の場合、`redirect("/login?next=/dashboard")` を実行し、ログインページへリダイレクトさせる（クエリパラメーター `next` を付与）。
  - 認証済みの場合、以下のUI構造をレンダリングする。

【使用タグ】
- `<div>`（コンテナー）: 画面幅いっぱいの背景エリア。
  - `<div>`（内部ラッパー）: コンテンツの中央寄せエリア。
    - `<h1>`（タイトル）:「ダッシュボード」。大きく太字で表示。
    - `<p>`（説明文）:「認証済みユーザー専用ページです」。グレーのテキスト。

- 【参照】
  - `createClient`
  - `redirect`
  - `DashboardPage`

- 【命名】
  - `DashboardPage`

### ヒント

- `redirect`は`next/navigation`からインポートする。
- `createClient`は`@/lib/supabase/server`からインポートする。
- 非同期関数（`async`）としてコンポーネントを定義する。
- 使用クラス一覧:
  - `div（コンテナー）`: `max-w-7xl`, `mx-auto`, `px-4`, `sm:px-6`, `lg:px-8`, `py-12`, `bg-gray-50`, `min-h-screen`
  - `div（内部ラッパー）`: `max-w-3xl`, `mx-auto`
  - `h1（タイトル）`: `text-3xl`, `font-bold`, `text-gray-900`
  - `p（説明文）`: `mt-2`, `text-lg`, `text-gray-600`

### 解答例

```tsx
import { createClient } from "@/lib/supabase/server";
import { redirect } from "next/navigation";

export default async function DashboardPage() {
  const supabase = await createClient();

  const {
    data: { user },
    error,
  } = await supabase.auth.getUser();

  if (error || !user) {
    redirect("/login?next=/dashboard");
  }

  return (
    <div className="max-w-7xl mx-auto px-4 sm:px-6 lg:px-8 py-12 bg-gray-50 min-h-screen">
      <div className="max-w-3xl mx-auto">
        <h1 className="text-3xl font-bold text-gray-900">ダッシュボード</h1>
        <p className="mt-2 text-lg text-gray-600">
          認証済みユーザー専用ページです
        </p>
      </div>
    </div>
  );
}
```

## 課題B：ユーザー情報の表示（15分）

15分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

ユーザー情報を画面に表示するセクションを追加する。

- 対象ファイル: `src/app/dashboard/page.tsx`
- 処理内容:
  - 課題Aで取得した `user` オブジェクトのプロパティを使用して、ユーザー情報を表示する。
- 表示データ:
  - メールアドレス: `user.email` を表示。
  - ユーザーID: `user.id` を表示。
  - 作成日時: `user.created_at` を `new Date(user.created_at).toLocaleString("ja-JP")` で日本ロケールの日時文字列に変換して表示。
- 構造:
  - タイトルの下に、ユーザー情報を表示するセクションを追加する。
  - ヘッダー部分: タイトル「ユーザー情報」と説明「あなたのアカウント情報」。
  - 詳細リスト: メールアドレス、ユーザーID、作成日時を表示。

【使用タグ】
- `<div>`（セクション）: 白背景、影付きのカードスタイル。
  - `<div>`（ヘッダー）: セクションのタイトルエリア。

## 課題C：ログアウト機能の実装（5分）
### 仕様

ログアウトボタンを追加し、クリック時にユーザーをログアウトさせる。

- 対象ファイル: `src/app/dashboard/page.tsx`
- 処理内容:
  - フォーム送信時に `signOut` 関数を実行するように設定する。
- 構造:
  - ユーザー情報セクションの下にログアウトボタンを追加する。
  - `form`要素の`action`属性に`signOut`を指定する。

【使用タグ】
- `<div>`（ラッパー）: ボタンの配置エリア。
  - `<form>`: Server Actions呼び出し用のフォーム。
    - `<button>`:「ログアウト」。赤色の背景、白文字のボタン。

- 【参照】
  - `signOut`

### ヒント

- Server Actionsは`form`の`action`属性で直接呼び出せる。
- ボタンは`type="submit"`にする。
- 使用クラス一覧:
  - `div（ラッパー）`: `mt-8`
