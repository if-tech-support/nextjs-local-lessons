## はじめに

Server Actionsを用いたサインアップ/サインイン/サインアウト処理を実装します。

## 目的

- Server Actionsによる認証処理の実装
- フォームデータの取り扱い
- 認証状態によるリダイレクト処理

## 学習対象のスキル

- Server Actions
- Supabase Authentication
- Next.js Cache & Navigation (revalidatePath, redirect)

## 課題A：サインアップ機能の実装（15分）

15分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

新規登録処理を行うServer Actionを作成します。

- 作成するファイル: `src/lib/actions.ts`
- `signUp`関数をエクスポートする
  - 引数: `formData: FormData`
  - 戻り値: `Promise<AuthError | null>`
  - 処理内容:
    1. `formData`から`email`と`password`を取得する
    2. `createClient`でSupabaseクライアントを作成する
    3. `supabase.auth.signUp`でサインアップ処理を実行する
    4. エラーが発生した場合は、エラーメッセージを含むオブジェクトを返す
    5. 成功した場合は、`revalidatePath`でルートレイアウトを更新し、`/dashboard`へリダイレクトする

### ヒント

- ファイルの先頭に`'use server'`を記述する
- `next/cache`から`revalidatePath`をインポートする
- `next/navigation`から`redirect`をインポートする
- `@/lib/supabase/server`から`createClient`をインポートする
- `@/types/auth`から型定義をインポートする

### 解答例

```ts
'use server';

import { revalidatePath } from 'next/cache';
import { redirect } from 'next/navigation';
import { createClient } from '@/lib/supabase/server';
import { AuthFormData, AuthError } from '@/types/auth';

export async function signUp(formData: FormData): Promise<AuthError | null> {
  const data: AuthFormData = {
    email: formData.get('email') as string,
    password: formData.get('password') as string,
  };

  const supabase = await createClient();

  const { error } = await supabase.auth.signUp({
    email: data.email,
    password: data.password,
  });

  if (error) {
    return { message: error.message };
  }

  revalidatePath('/', 'layout');
  redirect('/dashboard');
}
```

## 課題C：サインアウト機能の実装（5分）

### 仕様

ログアウト処理を行うServer Actionを追加します。

- 編集するファイル: `src/lib/actions.ts`
- `signOut`関数をエクスポートする

  - 戻り値: `Promise<void>`（またはエラーオブジェクト）
  - 処理内容:
    1. `createClient`でSupabaseクライアントを作成する
    2. `supabase.auth.signOut`でサインアウト処理を実行する

### ヒント

- 引数は不要
- リダイレクト先はトップページ

### 解答例

```ts
// signIn関数の下に追加
export async function signOut() {
  const supabase = await createClient();

  const { error } = await supabase.auth.signOut();

  if (error) {
    return { message: error.message };
  }

  revalidatePath('/', 'layout');
  redirect('/');
}
```
