## はじめに

アプリケーション全体で使用する共通レイアウトとコンポーネントを作成します。ヘッダーとフッターを配置し、認証状態に応じたナビゲーションを実装します。

## 目的

アプリケーション全体で使用する共通レイアウトとコンポーネントを作成し、認証状態に応じたナビゲーション機能を実装します。

## 学習対象のスキル

- Supabase Auth

## 課題A：ヘッダーコンポーネントの作成（12分）

12分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

認証状態に応じたナビゲーションを持つヘッダーコンポーネントを作成します。

- 作成するファイル: `src/app/components/Header.tsx`
- アプリタイトル:「AuthMini」クリックでトップページへ遷移
- ナビゲーション: 認証状態に応じて表示を切り替え

【使用タグ】
 - （新規）`<header>`: 白背景。薄い境界線と控えめなシャドウで区切る。
   - （新規）`<div>`（コンテンツラッパー）: 最大幅を制限し中央寄せ。左右の余白は画面幅に応じて調整。
     - （新規）`<div>`（上部バー）: 横並びのフレックス。左右に要素を配置し、縦方向中央揃え。高さは約64pxで固定。
       - （新規）`<div>`（ロゴエリア）: 横並びのフレックス。縦方向中央揃え。
         - （新規）`<Link>`（タイトル）: 大きめで太字の濃いグレー文字。クリックでトップへ遷移。
       - （新規）`<nav>`: ナビ項目を横並びにして縦中央揃え。子要素間に水平方向の間隔。
         - （新規）`<Link>`（ダッシュボード）: 薄いグレー文字でホバー時に濃く。小さめ太字、角丸と内側余白つき。
         - （新規）`<Link>`（ログイン）: ブルーの塗りつぶしボタン。ホバーで濃く。白文字・小さめ太字・角丸と内側余白。

### ヒント

- 認証状態は`createClient`で取得
- 条件付きレンダリングでナビゲーションを切り替え
- 使用クラス一覧:
  - `header`: `bg-white`, `shadow-sm`, `border-b`
  - `div（ラッパー）`: `max-w-7xl`, `mx-auto`, `px-4`, `sm:px-6`, `lg:px-8`
  - `div（上部バー）`: `flex`, `justify-between`, `items-center`, `h-16`
  - `Link（タイトル）`: `text-xl`, `font-bold`, `text-gray-900`
  - `nav`: `flex`, `items-center`, `space-x-4`
  - `Link（ダッシュボード）`: `text-gray-700`, `hover:text-gray-900`, `px-3`, `py-2`, `rounded-md`, `text-sm`, `font-medium`
  - `Link（ログイン）`: `bg-blue-600`, `hover:bg-blue-700`, `text-white`, `px-4`, `py-2`, `rounded-md`, `text-sm`, `font-medium`

### 解答例

```tsx
import Link from "next/link";
import { createClient } from "@/lib/supabase/server";

export default async function Header() {
  const supabase = await createClient();
  const {
    data: { user },
  } = await supabase.auth.getUser();

  return (
    <header className="bg-white shadow-sm border-b">
      <div className="max-w-7xl mx-auto px-4 sm:px-6 lg:px-8">
        <div className="flex justify-between items-center h-16">
          <div className="flex items-center">
            <Link href="/" className="text-xl font-bold text-gray-900">
              AuthMini
            </Link>
          </div>

          <nav className="flex items-center space-x-4">
            {user ? (
              <Link
                href="/dashboard"
                className="text-gray-700 hover:text-gray-900 px-3 py-2 rounded-md text-sm font-medium"
              >
                ダッシュボード
              </Link>
            ) : (
              <Link
                href="/login"
                className="bg-blue-600 text-white px-4 py-2 rounded-md text-sm font-medium hover:bg-blue-700"
              >
                ログイン
              </Link>
            )}
          </nav>
        </div>
      </div>
    </header>
  );
}
```

## 課題C：レイアウトの設定（8分）

8分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

`layout.tsx`に共通レイアウトを設定し、ヘッダーとフッターを配置します。

- 編集するファイル: `src/app/layout.tsx`
- メタデータの設定: タイトル「AuthMini - 認証機能付きダッシュボード」、説明文を追加
- HTML言語設定: `lang="ja"`
- レイアウト構成: ヘッダー、メインコンテンツ、フッターの縦並び

【使用タグ】
 - （新規）`<html>`: HTMLの言語を日本語に設定。
   - （新規）`<body>`: フォントをなめらかに表示。画面高いっぱいを最低の高さに。縦方向のフレックスレイアウトで全体を構成。背景色は薄い灰色。
     - （新規）`<Header>`: 画面上部の共通ヘッダーを表示。
     - （新規）`<main>`: 残りの縦スペースをすべて占有してメインコンテンツを表示。
     - （新規）`<Footer>`: 画面下部の共通フッターを表示。

### ヒント

- メタデータは`Metadata`型を使用
- フォント変数は`className`で適用
- 使用クラス一覧:
