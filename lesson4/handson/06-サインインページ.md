## はじめに

既存ユーザーがログインするためのサインインページを実装します。サインアップページと同様にClient Componentとして作成し、Server Actionsと連携して認証処理を行います。また、認証済みユーザーがアクセスした際のリダイレクト処理も実装します。

## 目的

- サインインフォームのUI実装
- 認証状態の確認とリダイレクト制御
- Server Actions（`signIn`）との連携
- 認証エラーの適切な表示とハンドリング

## 学習対象のスキル

- Client Component (`use client`)
- React Hooks (`useState`, `useEffect`)
- Next.js Navigation (`useRouter`)
- Supabase Browser Client (`createClient`)
- Server Actionsの呼び出し

## 課題B：状態管理と認証チェックの実装（10分）

10分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

状態管理と認証チェック機能と認証チェック中の表示を実装します。

- 対象ファイル: `src/app/login/page.tsx`
- 状態管理:
  - `error`: エラーメッセージ（初期値 `null`）
  - `isLoading`: 送信中のローディング状態（初期値 `false`）
  - `isCheckingAuth`: 認証確認中の状態（初期値 `true`）
- 認証チェック機能 (`useEffect`):
  - 依存配列: `[router]`
  - 内部処理（`checkAuth` 非同期関数）:
    - `createClient()` でSupabaseクライアントを初期化。
    - `await supabase.auth.getUser()` を実行し、現在のユーザー情報を取得。
    - 取得した `data.user` を確認:
       - ユーザーが存在する場合: `router.push('/')` を実行してトップページへリダイレクトし、処理を終了。
       - ユーザーが存在しない場合: `setIsCheckingAuth(false)` を実行して認証チェック完了とする。
- 構造（認証チェック中）:
  - 画面中央にローディングスピナーと「認証状態を確認中」のテキストを表示。

【使用タグ】（ローディング表示）
- `<div>`（画面全体）: 画面中央寄せレイアウト。背景色は薄いグレー。
  - `<div>`（ローディング表示）: 認証チェック中に表示。
    - `<div>`（スピナー）: 青色の回転する円。
    - `<p>`（テキスト）:「認証状態を確認中」。

### ヒント

- `src/lib/supabase/client` から `createClient` をインポートします。
- `next/navigation` から `useRouter` をインポートします。
- 認証チェック中はフォームを表示せず、ローディング表示のみを返します。
- 使用クラス一覧（ローディング表示）:
  - `div（画面全体）`: `min-h-screen`, `flex`, `items-center`, `justify-center`, `py-12`, `px-4`, `sm:px-6`, `lg:px-8`, `bg-gray-50`
  - `div（ローディング表示）`: `text-center`
  - `div（スピナー）`: `animate-spin`, `rounded-full`, `h-8`, `w-8`, `border-b-2`, `border-blue-600`, `mx-auto`
  - `p（テキスト）`: `mt-2`, `text-gray-600`

### 解答例

```tsx
'use client';

import { useState, useEffect } from 'react';
import { useRouter } from 'next/navigation';
import Link from 'next/link';
import { createClient } from '@/lib/supabase/client';

export default function LoginPage() {
  const [error, setError] = useState<string | null>(null);
  const [isLoading, setIsLoading] = useState(false);
  const [isCheckingAuth, setIsCheckingAuth] = useState(true);
  const router = useRouter();

  // ログイン状態をチェック
  useEffect(() => {
    const checkAuth = async () => {
      const supabase = createClient();
      const {
        data: { user },
      } = await supabase.auth.getUser();

      if (user) {
        // ログイン済みの場合はルートにリダイレクト
        router.push('/');
        return;
      }

      setIsCheckingAuth(false);
    };

    checkAuth();
  }, [router]);

  async function handleSignIn(formData: FormData) {
    console.log('Sign in');
  }

  // 認証チェック中はローディング表示
  if (isCheckingAuth) {
    return (
      <div className="min-h-screen flex items-center justify-center py-12 px-4 sm:px-6 lg:px-8 bg-gray-50">
        <div className="text-center">
          <div className="animate-spin rounded-full h-8 w-8 border-b-2 border-blue-600 mx-auto"></div>
          <p className="mt-2 text-gray-600">認証状態を確認中</p>
        </div>
      </div>
    );
  }

  return (
    // 省略
    // 課題Aで作成したJSXをそのまま使用
    <div className="min-h-screen flex items-center justify-center py-12 px-4 sm:px-6 lg:px-8 bg-gray-50">
      {/* 省略 */}
    </div>
  );
}
```

## 課題C：サインイン処理の実装（10分）

10分ほどヒントを参考にして仕様どおりにコーディングに挑戦し、その後に解答例で確認しましょう。

### 仕様

- 対象ファイル: `src/app/login/page.tsx`
- 関数: `async function handleSignIn(formData: FormData)`
  - 引数: `formData`（FormData型）- フォームの入力値
  - 戻り値: `Promise<void>`
  - 処理詳細:
    - 開始処理:
      - `setIsLoading(true)` を実行。
      - `setError(null)` を実行。
    - サインイン実行:
      - `try` ブロック内で `await signIn(formData)` を実行。
    - 結果判定:
      - 戻り値 (`result`) が存在する場合（エラー時）:
        - `setError(result.message)` を実行。
      - 戻り値がない場合（成功時）:
        - 何もしない（Server Action側でリダイレクトされるため）。
    - 例外処理:
      - `catch` ブロックでエラーを捕捉。
      - `setError` に `'ログインに失敗しました: ' + error` を設定。
    - 終了処理:
      - `finally` ブロックで `setIsLoading(false)` を実行。

### ヒント

- `src/lib/actions` から `signIn` をインポートします。
- `try-catch` ブロックを使用して予期せぬエラーも捕捉します。

### 解答例

```tsx
// 省略

// 省略

  // 省略

  async function handleSignIn(formData: FormData) {
    setIsLoading(true);
    setError(null);

      const result = await signIn(formData);
      if (result) {
        setError(result.message);
      }
      // 成功時はServer Actionでredirectされるため、ここでは何もしない
    } catch (error) {
      setError(`ログインに失敗しました: ${error}`);
    } finally {
      setIsLoading(false);
    }
  }

  // 省略
}
```
